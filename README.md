# 📚 ReadHub

ReadHub is a modern full-stack web application where users can explore, manage, and interact with books. It features secure authentication, a clean UI, and protected routes to ensure a smooth and safe user experience.

🌐 **Live Site:** https://sagorteasc-readhub.vercel.app/

---

## 🚀 Features

- 🔐 Authentication system (Email & Google)
- 👤 User profile management
- 📚 Browse and view book collections
- 🔒 Protected/private routes
- ⚡ Fast and responsive UI
- 🎨 Smooth animations for better UX

---

## 🛠️ Tech Stack

**Frontend:**

- Next.js
- React.js
- Tailwind CSS
- Animate.css

**Backend & Auth:**

- BetterAuth
- MongoDB
